# 📊 Growth Analytics Dashboard

An end-to-end Business Intelligence project using **MySQL** and **Apache Superset** to analyze business performance, sales trends, customer behavior, and profitability.

> 🚧 Project Status: In Progress

---

## Tech Stack

- MySQL
- SQL
- Apache Superset
- Docker

---

## Completed

- Database setup
- Data cleaning
- ETL process
- Sales analytics view
- Business SQL analytics

---

## Business Analysis

Implemented SQL queries for:

- Overall business performance
- Monthly sales trend
- Category performance
- Sub-category performance
- State-wise sales
- Top customers
- Loss-making products
- Target vs Actual sales analysis
